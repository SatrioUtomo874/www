01 / FILE KOORDINAT

Masukkan template Excel

XLSX
Cara membaca koordinat

Folder 1 memakai Latitude di B2 dan Longitude di C2. Folder 2 memakai B3/C3, lalu berlanjut sesuai nomor folder. Kolom D boleh diisi nama folder keluaran (opsional), misalnya Area Utara; hasilnya menjadi 1. Area Utara. Jika D dikosongkan, nama folder tetap angka seperti semula. Gunakan titik (.) sebagai pemisah desimal, misalnya -7.257500 dan 112.752100. Template memakai format teks agar titik tetap tampil meskipun pengaturan regional Excel menggunakan koma. Ganti nilai contoh sebelum memproses foto milikmu. Jika Excel mengubah titik menjadi pemisah ribuan, aplikasi akan menampilkan bantuan pemulihan dan meminta konfirmasi sebelum tagging.

02 / FOLDER FOTO

Pilih folder induk

NOMOR 1, 2, 3...
Contoh susunan folder 
Nama Folder Bebas/
├── 1/   (atau 1. Area Utara/) · koordinat dari baris 2
├── 2/   (atau 2. Area Selatan/) · koordinat dari baris 3
└── 3/   Foto untuk koordinat baris 4

Nama folder utama bebas. Pilih folder apa pun yang di dalamnya berisi subfolder bernama angka seperti 1, 2, 3, dan seterusnya. Kamu juga boleh menamai subfolder seperti 1. Area Utara; nomor di depannya tetap dipakai untuk mencocokkan koordinat Excel. Nama file foto bebas; semua JPG/JPEG di dalam subfolder angka akan dibaca, termasuk yang berada di subfolder lebih dalam.

Pratinjau pencocokan
Folder hasilLatitudeLongitudeFotoStatus

Folder yang nomornya melebihi nomor koordinat terakhir di Excel akan diabaikan. Baris koordinat kosong atau tidak valid akan dilewati.

!
Titik desimal kemungkinan diubah Excel

Angka koordinat terlihat seperti pemisah ribuan, misalnya -740118977777778. GeoTag Studio dapat menyusun kembali kemungkinan titik desimal, tetapi posisi aslinya harus kamu periksa dengan sumber koordinat.

Penting: Excel dapat membulatkan angka panjang setelah dianggap sebagai angka biasa. Pemulihan ini hanya menyusun kembali tanda titik yang hilang dan mungkin tidak mengembalikan digit terakhir yang sudah diubah Excel. Selalu cocokkan hasilnya dengan sumber koordinat.
